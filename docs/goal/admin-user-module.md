# 管理员用户管理模块

管理员用户是登录 Easy1Auth 管理后台并管理租户资源的账号，与用户池中的普通用户相互独立。

一个管理员可以加入多个租户，并在已加入的租户之间切换。管理员在不同租户中可以拥有不同的角色和权限。

## 管理员列表

对当前租户下的管理员账号进行统一管理。

### 搜索表单字段

- 用户名
- 邮箱
- 手机号
- 状态
- 管理员角色

### 列表字段

- 用户名
- 邮箱
- 手机号
- 当前租户角色
- 状态
- MFA 状态
- 最后登录时间
- 创建时间

### 列表操作

- 查看管理员详情
- 编辑管理员信息
- 启用或禁用管理员
- 分配管理员角色
- 重置密码
- 重置 MFA
- 移出租户
- 删除管理员

## 创建管理员

### 前端表单字段

- 用户名
- 邮箱
- 手机号
- 初始密码
- 确认密码
- 管理员角色
- 状态

创建管理员时，将管理员账号与当前租户关联。用户名和邮箱必须唯一，密码需要符合当前密码策略。

支持通过邮件邀请管理员加入当前租户。受邀管理员完成注册后建立租户关联，并获得邀请时指定的管理员角色。

## 管理员详情

管理员详情包含：

- 基本信息
- 所属租户
- 当前租户角色
- 权限明细
- MFA 配置状态
- 最后登录时间
- 最近登录记录
- 最近操作记录

## 租户关联

- 一个管理员可以属于多个租户
- 管理员只能切换到自己已加入的租户
- 管理员在每个租户中的角色独立配置
- 移出租户只解除管理员与该租户的关联，不删除管理员账号
- 管理员失去最后一个租户关联后不能进入管理后台

## 管理员角色

管理员角色与用户池中的普通用户角色相互独立，使用管理员角色控制管理后台权限。

### 预设角色

- 租户所有者：拥有当前租户的全部权限
- 超级管理员：拥有除租户所有权操作外的全部管理权限
- 用户管理员：管理用户、用户组和岗位
- 应用管理员：管理应用和单点登录配置
- 安全管理员：管理安全策略、身份源和审计日志
- 只读管理员：只允许查看，不允许修改

### 角色能力

- 创建、编辑和删除自定义管理员角色
- 配置菜单权限和操作权限
- 为管理员分配一个或多个角色
- 查看角色合并后的最终权限
- 系统预设角色不可删除

## 状态管理

管理员状态包括：

- 正常：允许登录和访问已授权功能
- 禁用：禁止登录，已有会话立即失效
- 待邀请：已创建邀请但尚未完成注册
- 邀请过期：邀请链接已失效

## 安全管理

- 管理员密码必须符合租户密码策略
- 支持管理员主动修改密码
- 支持有权限的管理员重置其他管理员密码
- 支持强制管理员下次登录时修改密码
- 支持重置管理员 MFA 配置
- 禁用、移除或删除管理员后立即撤销其访问令牌和会话
- 敏感操作需要二次确认

## 权限约束

- 管理员只能查看和管理当前租户的数据
- 后端必须校验管理员与请求租户的关联关系，不能直接信任客户端传入的租户 ID
- 管理员不能为自己授予当前不具备的权限
- 管理员不能禁用、移除或删除自己
- 租户所有者不能被普通管理员修改、移除或删除
- 每个租户至少保留一个可用的租户所有者
- 只有租户所有者可以转移租户所有权

## 审计日志

以下操作需要写入审计日志：

- 创建、编辑、启用、禁用和删除管理员
- 邀请、重新邀请和撤销邀请
- 分配或移除管理员角色
- 加入或移出租户
- 重置密码和 MFA
- 转移租户所有权
- 管理员登录、退出和登录失败

## 实现说明

当前实现与上述完整设计存在以下 intentional divergence：

- **管理员账号自注册，无后台创建 UI**：管理员通过登录/注册流程自行创建账号，当前版本未提供「新增管理员」界面。后续如需平台管理员代创账号，可在此模块扩展。
- **「删除管理员」当前表现为「移出租户」**：列表中的删除操作仅解除该管理员与当前租户的关联，不会物理删除管理员账号。当管理员失去最后一个租户关联后将无法进入管理后台。
- **管理员邀请机制暂不在范围内**：邮件邀请、邀请链接、待邀请/邀请过期状态均未实现。管理员加入租户通过自注册 + 后台分配角色完成。
- **命令行 QA 验证不替代未来自动化测试**：当前通过手动接口调用和构建验证确认功能可用，后续应补充 vitest/jest 单元测试和 Playwright E2E 测试。

## 验收标准

- 管理员列表只能展示当前租户下的管理员
- 管理员无法通过修改租户请求头访问未加入的租户
- 创建、编辑、状态变更、角色分配和移出租户功能可正常使用
- 管理员权限变更后立即生效
- 禁用或移除管理员后，其已有会话立即失效
- 系统始终阻止删除最后一个租户所有者
- 所有管理员管理操作都能在审计日志中查询
