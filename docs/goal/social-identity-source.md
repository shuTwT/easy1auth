# 社会化身份源

对接社交登录，使应用支持社交软件授权登录

## 来源

- 微信
  - 微信扫码
  - 小程序扫码
  - 公众号网页授权
  - 微信小程序
- QQ(暂不支持)
  - QQ扫码
  - QQ移动端
- Github
- Gitee
- 抖音(暂不支持)
  - 抖音扫码
- 支付宝(暂不支持)

## 限制

管理员用户只能添加指定的身份源，不能添加自定义身份源。所以用户不需要填写端点。

## 身份源分类

社会化身份源配置微信、GitHub、Gitee 等社会化登录。飞书网页授权归属于企业身份源。
飞书通讯录导入与事件同步归属于同步身份源，使用独立配置，不参与登录授权。

前端页面、类型和 API 模块的对应关系见 [身份源分类与命名](../identity-sources.md)。
